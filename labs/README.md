# Labs

Labs turn a concept into repeatable evidence. Each lab should include:

1. objective and prerequisite;
2. system boundary and data classification;
3. exact setup using placeholders only;
4. positive test;
5. unauthorized or failure-path test;
6. restart/persistence test when relevant;
7. observed result and limitation;
8. cleanup/recovery steps;
9. review questions.
