# Project applications

## OpenClaw Wearables

https://github.com/simon5530/openclaw-wearables

Applies BYOA, compatible APIs, loopback networking, reverse proxying, private overlay
networks, bearer authentication, session lifecycle, model fallback, multi-user
isolation, and approval-gated external actions.

## Agent Liaison

https://github.com/simon5530/agent-liaison

Applies OAuth 2.0, calendar standards, webhooks, idempotency, state machines, soft
holds with TTL, optimistic concurrency, least privilege, delegated authority, and
privacy-preserving derived data.

## Mini Energy AI Lab

https://github.com/simon5530/mini-energy-ai-lab

Applies staged simulation, explicit physical units and sign conventions, versioned
telemetry contracts, provenance and quality labels, requested-versus-applied action
records, executable invariants, and transport-independent serialization before later
protocol or agent integration.
